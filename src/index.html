    How exits work

    The tree below is rooted at wherever you're currently standing and branches out three exits deep. The first level shows everywhere you could go from here, including "?" for anywhere you haven't been yet and "varies" where the game itself can't say for sure. The second and third levels only continue through rooms you've actually already found, so the deeper part of the tree stays a map of what you know rather than repeating guesses at every level. A "->" before an exit means it's one-way -- there's no exit back that way once you go. A few locations (the Cave, the Maze, the Mirror Room, the Coal Mine...) are really more than one identical-looking room the game can't tell apart by name alone -- but this map also watches which way you actually move, and since those rooms' real layouts are completely fixed underneath, it can usually work out exactly which one you're in as you walk around, keeping the tree exact instead of "varies" even deep in the Maze. It only falls back to a guess -- "varies" for an exit, or a dotted border if a direction doesn't even exist from every version of that room -- right after something throws the tracking off (a blocked or conditional exit that didn't actually go through, or a random effect like the bat in the mines). From there it locks back onto the exact room automatically as soon as you reach somewhere this map can identify by name alone again -- it won't resync just from wandering further through the same ambiguous area. Some exits only exist once something specific happens elsewhere (a door propped open, a puzzle solved) -- those get a dashed border, with what's needed in the tooltip; since this map can only watch the room name and your movement, not object or flag state, it can't tell whether that condition's already been met, so treat that as "here's what to check," not as a live yes/no.
